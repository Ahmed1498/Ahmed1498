## 🚀 Featured Projects

### 🧏 Taraf — AI Accessibility Platform (Graduation Project)
A Flutter-based accessibility app powered by a FastAPI backend and multiple AI modules.
- **RAG Accessibility Assistant:** FAISS semantic search over Google Sheets data, Arabic & English support, conversational memory. Improved answer accuracy by **76%**.
- **Resilient LLM layer:** multi-provider fallback (Gemini, Cohere, Grok) reaching a **99.8%** request success rate.
- **Sign Language Translation:** OpenAI Whisper (speech-to-text) + Hugging Face models → Egyptian Sign Language, rendered by a 3D avatar in Unity WebGL.
- **SQL-connected agent:** chatbot reasons over Supabase/PostgreSQL data in real time, alongside Auth and Storage integration.

`Python` `FastAPI` `RAG` `FAISS` `Whisper` `Hugging Face` `Supabase` `Flutter` `Unity`

### 🎙️ SmartCast — PDF-to-Podcast Converter
Converts academic PDFs into English podcasts with summarization and auto-generated quizzes.
- Serverless pipeline on **AWS (S3, Lambda, EC2)** with LLM APIs for real-time audio generation.
- Increased content accessibility by **87%** and cut manual processing time by **63%**.

`Python` `AWS` `NLP` `LLM APIs`

### 😴 Driver Drowsiness Detection
Real-time computer vision system using head pose estimation from live video, with automatic alerts.
- Compared multiple ML models with 5-fold cross-validation; **SVM** performed best at **83.5%** average accuracy.

`Python` `OpenCV` `TensorFlow/Keras` `NumPy` `scikit-learn`
